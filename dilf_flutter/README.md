DILF — Flutter MVP prototype

This prototype implements core UX for the DILF vision: onboarding, nightly goal entry, and a 3-bubble alarm that requires holding each bubble for 3 seconds to dismiss.

Prerequisites
- Flutter SDK installed: https://flutter.dev/docs/get-started/install

Run locally
```bash
cd dilf_flutter
flutter pub get
flutter run
```

Notes
- This is a prototype for UX validation. Native OS app-blocking and advanced integrations are not implemented.
- iOS DeviceActivity / FamilyControls integration is planned; see `IOS_DEVICE_ACTIVITY_PLAN.md` for entitlement and extension scaffolding.
